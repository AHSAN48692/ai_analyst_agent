# 🤖 Automated AI Data Analyst Agent

## 📌 Project Overview

This Business Intelligence and workflow automation project focuses on transforming raw transactional spreadsheets into immediate executive intelligence. Using **n8n orchestration** and **Generative AI**, I engineered an autonomous agent that ingests raw data files, programmatically handles preprocessing data pipelines, computes key business metrics, and delivers dynamic summary reports directly to your inbox in under **5 minutes**.

## 📊 Business Metrics & Key Achievements

* **Automated Data Processing:** Designed zero-touch workflows eliminating manual data cleansing, parsing, and KPI formatting.
* **Rapid Lifecycle Execution:** Optimized execution loops ensuring end-to-end extraction and structural transformations finish within a **4 to 5-minute** window.
* **Visual Insight Enrichment:** Configured backend triggers to render essential visual graphs alongside structural textual metrics for clear data parsing.

---

## 💡 Key Business Insights

* **Autonomous Cleansing Engine:** Dynamically addresses missing datasets, performs value imputation, and guarantees integrity for analytics downstream.
* **GenAI Contextualization:** Powered by the **Google Gemini Chat Model**, the agent behaves like a live business consultant—uncovering deep growth trends, anomalies, and tactical takeaways.
* **Seamless Notification Loop:** Eliminates dashboard friction by instantly building rich-text notifications and delivering summaries directly inside **Gmail**.
